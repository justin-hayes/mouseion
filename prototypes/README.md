# Design Prototypes

Historical design-exploration material. Nothing here is built, served, or part
of the current product contract.

- [`stitch/reading-horizon/`](stitch/reading-horizon/) — briefs, prompts, and a
  synthesis written for [Google Stitch](https://stitch.withgoogle.com/) visual
  explorations of an earlier "Reading Horizon" information architecture. Those
  explorations were superseded; each file states its status.

The current interface is specified in [`doc/design/`](../doc/design/README.md),
and the decisions that replaced these explorations are recorded in
[`doc/adr/`](../doc/adr/).
