# Latin Study evidence run, 2026-11-27

This is the evidence run for turning Latin's Study switch on ([#2768](https://github.com/justin-hayes/mouseion/issues/2768), spec [#2759](https://github.com/justin-hayes/mouseion/issues/2759), [ADR 0138](../adr/0138-study-for-source-evidence-languages.md) §6). It runs the production Study material path once per word and records what Study would have shown. Nothing here was written to a database. Justin judges each row; the last column is his.

## Threshold

Stated before the run (ADR 0138 §6): **at least 90% of Glosses acceptable, and no answer cites an invented sense ID.** Justin's judgement column decides the first half. The second half is counted automatically below.
