This is a bounded research assessment, not legal advice or dataset approval.

## Actual declarations

OGA's [README, lines 162–170](https://github.com/OperaGraecaAdnotata/OGA/blob/a69d917dbe117a307829977dd556e22f05ce0715/README.md#L162-L170)
explicitly licenses “this work” under **CC BY-SA 4.0**, and refers readers to
the original-text repositories for details. This **is an explicit license
declaration**: neither absence of a standalone LICENSE nor GitHub's detection
result negates it. No archive metadata shorthand is used to reject it.
The same README identifies the public example as annotation layers for
inspection (lines 93–101), and requests attribution for material in this
repository (lines 105–141). These statements support this local public-example
format inspection and publication of the bounded structural diagnostics.

The declaration does not erase separately applicable original-text rights.
README lines 11–15 name three upstream releases, including First1KGreek
`1.1.11352615003`; the example's digital identifier and OGA's bibliographic
record are source pointers, not a verified derivation from a particular
upstream XML. Exact original-text component applicability remains unverified.
This is not an archive-wide permission finding. No archive was acquired.

## Operations and publication choices

| Operation/component | This probe's disposition |
| --- | --- |
| Local example copying and computational inspection | Proceed under OGA's explicit declaration for the official inspection example, as authorized by the task. Preserve all original bytes and notices locally; do not claim independent upstream text clearance. No enrichment/provider API calls are made with the Greek inputs. |
| Public research prose, registry, structural diagnostic ledger | Publish with attribution below. The ledger contains node IDs, coordinates, group/graph structure, validation outcomes and hashes, **not Greek forms, lemmas, full text, IPA or copied bibliographic datasets**. Treat its source-derived structure conservatively as an OGA-derived diagnostic adaptation under CC BY-SA 4.0. This is an output-specific assessment, not “all statistics are unrestricted.” |
| Public original XML / full normalized sample / extracted reading text | **Not redistributed here.** Generated locally and retained privately. Full text/annotation redistribution needs exact underlying text/component review. Unicode escaping would not change this decision. |
| Eventual application bundling, exports or full-unit acquisition | **Not approved or tested.** Review the actual selected edition/release, operation, component notices and any adaptation/database obligations separately. This probe is not an acquisition route for the corpus archive. |
| Models, training corpora, external specifications | Models/training data were not acquired or run; no model/license approval is implied. PAULA documentation and CC legal text were read as specifications and retained locally, not bundled. Their rights are not inferred from OGA's declaration. |
| Reader and invented test fixtures | Mouseion-authored research code, not copied OGA code; the repository's code license remains unchanged. The data license does not automatically relicense the application. |

[CC BY-SA 4.0 legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode.txt)
§2(a)(1) permits reproduction and adaptation within the licensor's rights;
§2(a)(4) addresses technical modifications. §3(a) requires retained attribution,
source/license links and modification indications when sharing; §3(b) governs
shared adapted material. §4's database provisions have their own conditions;
they do not automatically attach to every computed number or every application.
The exact bytes and SHA-256 of the consulted legal text are in `inputs.json`.
No broad training-license survey or hypothetical application-license dispute
is made a prerequisite to this format probe.
