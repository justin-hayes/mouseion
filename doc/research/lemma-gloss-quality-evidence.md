# Lemma and gloss quality: deterministic evidence

Research note for [issue #1244](https://github.com/justin-hayes/mouseion/issues/1244), in the Book-analysis-to-deck map [#1237](https://github.com/justin-hayes/mouseion/issues/1237). Reviewed 2026-09-27. This is evidence and a proposed classification vocabulary, not an implementation specification.

## Findings

### Existing local evidence and boundaries

- Mouseion already uses Stanza tokenization, POS, lemma, and dependency parsing; German additionally uses `compound:prt` dependencies to restore the full separable-verb lemma. The stored canonical lemma, POS, morphology, and provenance are analysis outputs, not independently verified lexical facts ([`producer.py`](../../nlp/src/mouseion_nlp/producer.py), [`model_config.py`](../../nlp/src/mouseion_nlp/model_config.py); [Stanza project/model description](https://github.com/stanfordnlp/stanza)). Stanza models are downloadable ahead of time and can run locally; the application’s provisioned model set, not the abstract upstream language list, determines availability.
- A built-time optional SQLite dictionary index is already derived from raw English-Wiktionary Wiktextract/Kaikki JSONL for `de`, `it`, and `el`. It indexes only records with recognized POS and at least one gloss; it retains glosses, examples, topic/tag metadata, selected forms, and source version. The generated artifact can be used offline, while rebuilding/downloading needs the upstream dump ([`README.md`](../../README.md#refreshing-the-dictionary-index), [`derive_dictionary_index.py`](../../nlp/scripts/derive_dictionary_index.py), [dictionary feature](../features/dictionary-gloss-enrichment.md)). No committed index was available to measure corpus-token coverage during this research.
- Runtime lookup is keyed by language + normalized lemma + UPOS. Deterministic simplified Lesk orders senses by word overlap in a ±5-token/dependency context and falls back to the source’s primary sense on ties/low score; an optional consented provider can select indices from the frozen top-eight sense candidates or supply a fallback gloss ([`lexical.go`](../../internal/enrichment/lexical.go), [ADR 0069](../adr/0069-llm-sense-selection-and-fallback-gloss.md)). This is already explainable, but neither overlap nor a well-formed dictionary entry proves contextual fit. The LLM overlay is also not ground truth; it can misselect or author a bad fallback.
- Existing sentence quality scoring can be reused only as surrounding-card evidence: it rejects structural issues and ranks complete example sentences; it does not validate token lemmas or dictionary senses ([sentence-quality feature](../features/sentence-quality-scoring.md)). ADR 0078/current-reading snapshots and frozen prepared-deck inputs mean any later assessment must name which exact analysis and dictionary version it assessed ([ADR 0078](../adr/0078-book-dispositions-and-current-reading.md), [durable deck contract](../features/durable-prepared-deck-translation.md)).

### Deterministic checks worth separating

These checks can be deterministic and auditable; only the first group is appropriate for automatic exclusion without review.

| Signal | Strong automatic rejection / correction candidate | Review signal (not proof) |
|---|---|---|
| **Structural/identity validity** | Empty lemma, malformed canonical form, impossible/missing POS, token span or source offsets inconsistent with the source; malformed dictionary record. | Unicode/case/diacritic normalization changed the surface substantially; punctuation, clitic, or tokenization edge case. Preserve raw surface and raw lemma for diagnosis. |
| **Form ↔ lemma** | The exact source form has an explicit Wiktextract `form_of` link to another indexed lemma and compatible POS, and does not also appear as a valid lemma/lexicalized homograph. Consider correction only when the mapping is unique. | Inflectional-form tag matches an apparent token/form (case, number, person, tense, mood, degree); a local dictionary inflection table or paradigm generator predicts the surface from the proposed lemma; another lexicon agrees. Wiktextract forms support exact/feature checks but the source documents their availability as uneven ([schema fields](https://github.com/tatuylonen/wiktextract#format-of-the-extracted-word-entries)). Missing form evidence is not a mismatch. |
| **Lemma/POS support** | None from dictionary absence alone. A hard reject can be limited to structurally impossible outputs or a unique explicit mismatch. | Exact normalized lemma+UPOS lookup; compatible Wiktionary POS/sense tags; independent lexicon agreement; UPOS-conditioned corpus evidence. Different dictionary taxonomies (e.g. conjunction vs `CCONJ`/`SCONJ`) and homographs require mapping, not string equality. |
| **Non-lexical/proper noun** | Reject obvious non-language/control-token artifacts using strict, documented token-shape rules only. | `PROPN`, capitalization, entity/dependency clues, one-off occurrence, title/name style, or no common-word dictionary entry. These are weak individually: names can be meaningful vocabulary, sentence-initial capitalization is ordinary, and dictionaries are incomplete. Keep as review/suppress-from-card option, not silently mark “bad lemma.” |
| **Gloss shape** | Empty gloss; invalid markup/control characters; excessive length; known extraction placeholder/template residue; duplicate identical gloss entries. | Gloss is multiword/technical, has punctuation, translation alternatives, or unfamiliar words; source sense is tagged archaic, regional, figurative, slang, or specialized. Wiktextract explicitly carries qualifiers/topics separately and notes unknown qualifier cases, so terse extracted gloss text can lose useful qualification ([schema](https://github.com/tatuylonen/wiktextract#word-senses)). |
| **Sense/context fit** | No deterministic signal can safely prove “wrong sense” in general from bag-of-words overlap. | Compare context-content lemmas and dependency role to gloss/examples/topics/tags; fixed-phrase match; occurrence consistency across concordance; rank all senses and report margin/top-two tie. A high overlap can be accidental or reflect a related sense; low overlap can be a perfectly valid paraphrase. Preserve `uncertain` rather than turn a score threshold into fact. |

Avoid one opaque “quality score.” Expose bounded reason codes, dimensions (lemma/POS, form relation, lexicality, gloss form, context fit), the evidence source/version, and outcome. A practical shared outcome vocabulary:

- **pass / supported** — sufficient positive evidence for the particular check; does not mean universally correct.
- **reject / invalid** — only for deterministic structural impossibility or an unambiguous contradiction.
- **review / uncertain** — conflicting or weak signals, low-margin sense rankings, proper-name candidates, or language/resource gaps.
- **not assessed** — no applicable/available resource, no gloss/example/context, unsupported feature, or check not run. Never conflate “not found” with “not a word.”

### Primary-source data, coverage, licensing, offline limits

- **Wiktextract/Kaikki: current best local enrichment source.** Wiktextract describes its output as extracted Wiktionary entries with language, form, POS, senses/glosses, qualifiers, topics, examples and form-of/alt-of links, while explicitly saying coverage differs by edition/language ([upstream README/schema](https://github.com/tatuylonen/wiktextract#overview), [Kaikki raw data](https://kaikki.org/dictionary/rawdata.html)). Kaikki currently lists English-gloss machine-readable German, Italian, and Greek dictionaries ([publisher home](https://kaikki.org/)). Mouseion filters these records and provides a no-service SQLite runtime path. Upstream Wiktionary-derived data carries CC BY-SA 3.0 / GFDL terms in this repository’s attribution and refresh contract; preserve attribution/share-alike obligations when distributing the derived index ([repo README](../../README.md#refreshing-the-dictionary-index), [`attribution.go`](../../internal/dictionary/attribution.go)). Extractor software’s MIT license is not the data license. Lexical coverage, sense quality, and inflection coverage are not quantified upstream in a way that proves coverage of learner-book tokens; measure against Mouseion’s actual candidate denominator by language/POS and include unmatched plus malformed rows.
- **UD treebanks: evaluation, not broad lexical truth.** Universal Dependencies defines reusable UPOS, features, lemmas and dependency annotations ([UPOS and features](https://universaldependencies.org/u/pos/), [format](https://universaldependencies.org/format.html)). But annotation quality/lineage and text licenses are treebank-specific. German GSD documents mixed automatic/manual annotation and dataset caveats ([GSD README](https://github.com/UniversalDependencies/UD_German-GSD)); Italian ISDT reports a 278,429-word corpus and CC BY-NC-SA 3.0 (not a permissive production lexicon) ([ISDT README](https://github.com/UniversalDependencies/UD_Italian-ISDT)); Greek GDT reports only 2,521 sentences / 61,673 tokens and CC BY-NC-SA 3.0 ([GDT README](https://github.com/UniversalDependencies/UD_Greek-GDT)). Use available legal splits for held-out parser error estimates and fixture cases, not runtime broad-coverage checks. Check text and annotation terms separately before redistribution; some corpora distinguish them.
- **Inflectional resources can be candidate validators.** Wiktionary form records and Mouseion’s existing German verb principal-parts / noun plural and gender/article fields permit cheap exact checks. They are partial, sense/variety-sensitive, and sometimes ambiguous; never infer “wrong lemma” merely because a predicted form is absent. For higher coverage, evaluate a maintained morphological analyzer/generator per language against a manually checked test set before adopting it; none was established as an already-integrated, neutral-license, complete runtime source in this research. Avoid runtime network calls; ship/version local resources if used.
- **Stanza/UD model evidence.** Stanza’s upstream project supports multilingual tokenization, POS/morphology, lemmatization and dependency parsing, and provides downloadable trained packages ([project README](https://github.com/stanfordnlp/stanza), [models documentation](https://stanfordnlp.github.io/stanza/models.html)). This is useful upstream model output, not an independent validator of itself. Evaluate real Mouseion text manually/against held-out treebanks by language, with domain and genre stratification; downloaded model availability enables offline inference.

## Suggested measurement before thresholds

Create a manually adjudicated, stratified sample of actual analyzed occurrences and candidate cards for `de`/`it`/`el`, including dictionary hits/misses, POS, inflected forms, proper names, low-margin/multi-sense entries, no-gloss cases, and LLM/no-LLM outcomes. Label lemma identity, POS, form relation, lexicality, gloss readability/accuracy, contextual sense fit, plus annotator disagreement. Report each signal’s precision and recall separately; false rejection of good vocabulary, missed errors, incorrect gloss/sense, dictionary coverage, percent `not assessed`, and expected review effort are distinct outcomes. Treebank metrics alone do not answer dictionary-sense fit or learner-text domain transfer.
