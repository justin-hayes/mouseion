# EPUB-to-study prose-assumption audit

Exploration asset for [Audit: trace prose assumptions through extraction, analysis and study](https://github.com/justin-hayes/mouseion/issues/2144), not a specification or an accepted design. Date: 2026-10-17.

**Inspected application commit:** [`6e02d180b1015536127839e0a45953684c0e5a83`](https://github.com/justin-hayes/mouseion/commit/6e02d180b1015536127839e0a45953684c0e5a83). All application source links below pin that commit. This throwaway `research/poetry-pipeline-audit` branch adds only this inventory and bounded probes under `doc/research/`; do not merge it. No application code, schema, accepted policy, or domain vocabulary is changed.

## How to read the evidence

- **Executed** means a supplied synthetic example or existing regression test ran locally. It does not imply a German verse model was run.
- **Code-confirmed** means the specified live source path establishes behavior; edition-specific impact still needs a pinned EPUB.
- **Risk / unmeasured** means the magnitude, applicability, or linguistic correctness is not established here.
- Loss in extracted text is not loss of the original EPUB: acquired container bytes are retained. Retaining bytes in storage is not the same as presenting verse faithfully.

The probes use synthetic text, not an acceptance edition or a literary quotation. See [reproduction and results](poetry-audit/results.md), [Go overlay runner](poetry-audit/run.py), and [fake-pipeline producer probe](poetry-audit/producer_probe.py). Go overlays add virtual test files without editing application packages. Integration suites use isolated test databases and supplied analyzers/providers; they are not a live catalog → Stanza → external-LLM end-to-end test.

## Live path and evidence inventory

### 1. Acquisition retains the container, but reacquisition is not re-extraction migration

**Source:** [`internal/opds/service.go:161–215`, `acquire`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/opds/service.go#L161-L215); [`internal/epub/ingest.go:62–133`, `importForAcquisition` / `importBookForBook`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/epub/ingest.go#L62-L133); [`internal/persistence/epub_units.go:47–143`, revision resolution](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/persistence/epub_units.go#L47-L143).

**Code-confirmed:** the catalog route selects the first supported EPUB acquisition link, downloads it and passes its bytes to the EPUB service. The import extracts before checking acquisition identity; an existing owner-scoped source identity/content match returns the existing stored Source material without rewriting its snapshot/history. New content stores the exact EPUB bytes plus extracted full text, revision digest, units and Book link. Direct import also resolves the content revision by digest; an unchanged current revision does not write a new snapshot. Thus changing extraction code alone does not refresh an already acquired Book. Original bytes allow future recovery, but a safe re-extraction/version transition is not provided merely by ordinary reacquisition.

**Affected contract / tests:** immutable source revisions and acquisition idempotency. `internal/epub/ingest_test.go::TestImportForAcquisitionReturnsExistingSourceWithoutRewritingIt`; `internal/epub/ingest_integration_test.go::{TestImportPostgresOwnerIsolationHistoryAndDeletion, TestImportReimportRestoresPreviousRevision}`; `internal/persistence/epub_units_integration_test.go::TestPutSourceMaterialWithExtractedUnitsResolvesContentIdentity`. These suites passed. No external catalog/download was exercised in the new probes.

### 2. A readable unit is a readable spine resource, not a verse line or stanza

**Source:** [`internal/epub/epub.go:204–309`, `extractSpine`, `readDocument`, `appendUnit`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/epub/epub.go#L204-L309); [`internal/domain/epub_units.go`, `ExtractedUnit`, `ValidateOffsets`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/domain/epub_units.go).

**Code-confirmed preservation:** ordered nonempty linear XHTML resources become units with spine-based IDs, resource paths, titles/fallback provenance, manifest properties, navigation labels and landmark types. Nonlinear resources, navigation resources, unsupported media and empty extracted documents are skipped. Units are joined with `\n\n` in compatibility full text; half-open unit spans count Unicode code points and exclude the separators. The unit record retains resource-level provenance, not XHTML element IDs, classes, individual line ranges, speaker attribution or stanza membership.

**Affected contract / tests:** EPUB extraction envelope schema version is **1**, separate from EPUB version. Resource order, identity and offsets must remain reproducible. `internal/epub/epub_test.go::{TestPhaseOneEPUBFixturesMatchContract, TestExtractReadingOrderAndLocations, TestExtractOrderedUnitsAndNavigationMetadata, TestExtractSkipsEmptySpineDocuments}` and `internal/epub/contract_test.go::{TestExtractedUnitIdentityIsSpineBased, TestExtractedUnitsValidateUnicodeOffsetsAndSpineGaps, TestExtractedUnitsRejectOffsetInvariantViolations}` passed. **Risk:** a meaningful dramatic/poetic passage in a nonlinear resource is outside today's readable-unit contract; this has not been established for the acceptance edition.

### 3. Intra-resource extraction conflates line, paragraph and group breaks

**Source:** [`internal/epub/epub.go:501–605`, `extractXHTML`, `xhtmlExtractor`, `cleanSpace`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/epub/epub.go#L501-L605).

**Executed confirmed loss:** only local element names reach the extractor; attributes and CSS do not. Every recognized block boundary flushes nonempty text, `br` is a block, empty blocks disappear, and all output blocks use the same `\n\n` separator. Within each block `unicode.IsSpace` runs become one ordinary space, even inside `pre`. Probe observations:

| Input body | Extracted text, escaped |
| --- | --- |
| `<p>Alpha<br/>Beta<br/><br/>Gamma</p>` | `Alpha\n\nBeta\n\nGamma` |
| `<p>Alpha</p><p>Beta</p><p>Gamma</p>` | `Alpha\n\nBeta\n\nGamma` |
| `<pre>Alpha\nBeta\n\nGamma</pre>` | `Alpha Beta Gamma` |
| adjacent `span.line` elements without literal separation | `AlphaBeta` |
| `span.line` elements separated by a space | `Alpha Beta` |

Different verse/paragraph/group encodings therefore become indistinguishable in the extracted representation, and CSS-only line boundaries cannot be recovered from it. This does **not** show that all EPUBs encode verse this way, nor that pretty-printing whitespace is authorial. Speaker and stage-direction *words* survive ordinary body elements, but role/class distinctions do not: the probe returns `Faust\n\n(tritt auf)\n\nAlpha`, with no typed attribution. `head`, `style`, `script`, and `nav` content is deliberately skipped.

**Affected contract / tests:** authoritative extracted unit text and every later source offset. New `TestPoetryAuditExtraction` covers the six examples. Existing `internal/epub/epub_test.go::{TestExtractXHTMLNamedEntities, TestExtractMalformedXHTML, TestPhaseOneEPUBFixturesMatchContract}` passed and preserve prose punctuation/entity/paragraph expectations. There is no accepted verse-structure contract to regress against yet.

### 4. Main-text selection excludes whole units using declared landmarks only

**Source:** [`internal/epub/main_text.go:18–70`, `IdentifyMainText`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/epub/main_text.go#L18-L70); [`internal/analysis/jobs.go:1241–1276`, `fetchSnapshotWork`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/jobs.go#L1241-L1276).

**Code-confirmed:** a single `bodymatter` start and the first recognized back-matter landmark determine a contiguous selected run. Missing/multiple body starts or a contradictory empty run fall back to the complete snapshot. Recognized back matter: `backmatter`, `bibliography`, `index`, `glossary`, `colophon`. Selection is not a classifier, does not inspect line length or verse syntax, and does not delete excluded units from the acquired snapshot. Each selected unit is independently analyzed with its unit ID, resolved resource identifier, title and text. The global full-text separator is not sent between units.

**Affected contract / tests:** ADR 0066, not the superseded whole-scope language in ADR 0047. `internal/epub/main_text_test.go::TestIdentifyMainText` and `internal/analysis/jobs_integration_test.go::TestRiverAnalysisSelectsMainTextAndVersionsTheRun` passed. **Risk:** dedication, prologues or dramatic frames may lie before a declared body start; edition inspection must determine inclusion. Do not call every excluded ancillary unit a poetry loss.

### 5. Chunking preserves characters but can change linguistic context at RPC edges

**Source:** [`internal/analysis/chunk.go:9–68`, `splitSentences`, `chunkText`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/chunk.go#L9-L68); [`internal/analysis/jobs.go:1279–1356`, merge / `analyzeDocumentChunks`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/jobs.go#L1279-L1356); [`offsetResultLocations:1951–1963`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/jobs.go#L1951-L1963).

**Executed preservation / reinterpretation:** default limit is 100,000 code points. The lightweight splitter recognizes `. ! ?` only, without abbreviation/quotation logic; oversized pieces are hard-cut by rune count, possibly inside a word or group. No trimming or whitespace reconstruction occurs. At a forced limit of eight, `Äpfel\n\nblühen ohne Ende` becomes `["Äpfel\n\nb", "lühen oh", "ne Ende"]`, whose concatenation exactly equals the input. This is a boundary behavior probe, not evidence that ordinary *Faust* chunks are that small.

Each chunk is a separate pipeline invocation; merged output appends sentences, never rejoins/reparses cross-chunk syntax. Chunk-local sentence/token spans are shifted by the cumulative **code-point** count within the unit; the next unit restarts at zero. **Risk:** dependencies, separable particles, enjambment, abbreviations and speaker turns straddling a chunk/unit boundary lack joint analysis. Actual affected frequency is unmeasured.

**Affected contract / tests:** ADR 0013's bounded RPCs and reconstructibility. `internal/analysis/chunk_test.go::{TestChunkTextSplitsAtSentences, TestChunkTextHardCutsOverlongSentence, TestChunkTextReconstructsWithPunctuation}` and new `TestPoetryAuditChunksAndCounts` passed. Ordinary run identity uses explicit contract/config versions (`jobs.go:105–115`, `ordinaryAnalysisIdentity`, `normalizedArtifactHash`); it is not a digest of output sentence bytes or an automatic detector of a changed chunking algorithm. New semantics must not be assumed to refresh old immutable evidence automatically.

### 6. Go/Python transport carries literal text, but no typed verse structure

**Source:** [`proto/mouseion/v1/normalized_corpus.proto:26–111`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/proto/mouseion/v1/normalized_corpus.proto#L26-L111); [`internal/analyzer/grpc.go:45–82`, `Analyze`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analyzer/grpc.go#L45-L82); [`internal/analyzer/proto.go`, `ToProto`, `FromProto`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analyzer/proto.go); [`nlp/src/mouseion_nlp/server.py`, `AnalyzerServicer.Analyze`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/nlp/src/mouseion_nlp/server.py).

**Code-confirmed / executed adapter round trip:** request carries a language, exact document string and source ID/identifier/title. Sentence text, ordered tokens, locations and syntax cross the response. Neither Go nor server adapter applies line/space normalization. Newline text survives the Go conversion probe. SourceLocation is half-open Unicode-code-point offsets within **extracted unit text**, not EPUB bytes, XPath, printed line numbers, or full-Book positions. There are no line/stanza/speaker structures in this RPC contract; incidental characters can be retained without retaining their type.

**Affected contract / tests:** ADRs 0001/0011; protobuf major-version compatibility and frozen field numbers; `internal/analyzer/{grpc_test.go,proto_test.go,python_fixture_test.go}` passed. This audit did not start the Python gRPC service or assert wire-level verse segmentation.

### 7. Producer delegates sentence segmentation to Stanza; cleaned token surfaces are not source text

**Source:** [`nlp/src/mouseion_nlp/producer.py:125–145`, `_stanza_pipeline`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/nlp/src/mouseion_nlp/producer.py#L125-L145); [`Producer.analyze`, `_map_sentence`:211–355](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/nlp/src/mouseion_nlp/producer.py#L211-L355); [`model_config.py`, `DEFAULT_PROCESSORS`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/nlp/src/mouseion_nlp/model_config.py).

**Code-confirmed:** production runs `tokenize,pos,lemma,depparse`, uses provisioned models (`DownloadMethod.NONE`), and sets no custom verse or newline segmentation option. It calls the pipeline once per received chunk, maps returned sentences, copies `sentence.text`, and derives sentence bounds from the first/last emitted token. Word offsets prefer word spans, falling back to parent-token spans (important for multiword tokens). Missing dependency/head resolution raises an error. Roots become self-headed zero-based ordinals.

Token lexical surfaces remove edge punctuation/symbols while retaining apostrophes/internal punctuation; raw lemmas stay separate. Pipe alternatives select the first usable lemma, empty alternatives may drop a token, German canonicalization applies its versioned historical-spelling equivalents, and recognized dependency-linked separable particles reattach to the verb lemma. None of this rewrites authoritative sentence text. No NER processor is requested; German GDEX's entity-density factor uses `PROPN`, not a new NER run.

**Executed:** fake-pipeline probe passes `Äpfel\n\nblühen.` unchanged to the adapter, preserves text and spans `[0,14)`, and maps heads to `[1,1,1]`. The fake supplies segmentation and syntax: it cannot establish Stanza behavior or accuracy. **Risk:** if dropped tokens, inherited MWT spans or a model's text/span behavior disagree with the source slice, downstream morphology must degrade rather than invent alignment.

**Affected contract / tests:** `nlp/tests/test_producer.py::{test_maps_one_batch_stanza_result_to_versioned_artifact, test_maps_dependency_heads_through_multiword_tokens, test_cleans_edge_punctuation_without_changing_offsets_or_internal_punctuation, test_german_normalization_preserves_modern_sharp_s_and_maps_historical_forms, test_german_separable_verbs_reattach_and_ignore_homographs}` passed. All Python tests: 91 passed, three opt-in real pipelines skipped. External Stanza newline semantics and German-verse accuracy belong to [Research: German verse boundaries in Stanza and sentence-based study](https://github.com/justin-hayes/mouseion/issues/2146), not to this adapter probe.

### 8. Persistence retains the analyzed sentence stream independently of card eligibility

**Source:** [`internal/analysis/jobs.go:1359–1421`, atomic persistence](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/jobs.go#L1359-L1421); [`persistNormalizedCorpus`, sentence/token INSERTs and validation:1758–1893](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/analysis/jobs.go#L1758-L1893).

**Code-confirmed preservation:** sentence text and unit-relative spans, corpus-wide sentence ordinal, token ordinal, surface/raw and canonical lemma, POS, morphology, dependency/head and token spans are persisted in owner/run/corpus-scoped tables in the analysis transaction. Inserts do not flatten sentence newlines or limit persistence to vocabulary candidates. Empty sentences can be represented. The writer checks bigint offset conversion, required dependency, head range and self-headed root; it does **not** prove sentence text equals its authoritative unit slice here. These exercise real relational persistence with supplied analysis, not a production Stanza parse.

### 9. Vocabulary counts are token-based, not sentence-quality-based

**Source:** [`internal/selection/selection.go:212–308`, statistics, aggregation, `Effective`, `OccurrenceEligible`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/selection/selection.go#L212-L308); [`internal/persistence/vocabulary_browse_counts.go:127–174`, shared projection](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/persistence/vocabulary_browse_counts.go#L127-L174); [`internal/selection/eligibility.go:5–61`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/selection/eligibility.go#L5-L61); [`internal/persistence/current_reading_lifecycle.go:47–99`, Reading freeze](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/persistence/current_reading_lifecycle.go#L47-L99).

**Executed / code-confirmed:** eligible occurrences require a valid lemma, `NOUN/VERB/ADJ/ADV`, and not `compound:prt`; identity includes study language, canonical lemma, analyzed POS (plus the classical discriminator where applicable). Confirmed occurrence exclusions/corrections affect effective projections, not raw evidence. Sentence references retain full sentence text and token source location. The same two supplied eligible tokens count twice whether placed in one sentence or two; there is no minimum sentence length, finite-verb or newline test in counting. Sentence statistics *do* depend on segmentation: sentence count, median/p90 token lengths, empty/long sentences.

Current Book-deck eligibility is at least three in-Book occurrences, **or at least one in-Book and fifteen across current same-language analyzed Books including this Book**, subject to readiness and Known/Reserved exclusions. Generated provenance is not Known. Starting Reading freezes corpus-qualified candidates/references and counts; card omissions do not subtract them. Browse uses the shared effective projection, while immutable analyzer statistics remain the coverage denominator.

**Risk:** segmentation can indirectly change lemmas, POS, particles or tokenization, hence counts; synthetic regrouping does not measure that. With no typed role filter, eligible words in stage directions can count; `PROPN` speaker labels are excluded by POS, but mislabeled labels or ordinary nouns are not excluded merely for being a speaker. Whether directions/names should count is an undecided product policy, not an established bug.

**Affected contract / tests:** ADRs 0026, 0036, 0081, 0085 **as amended by 0090** (do not repeat the historical twice/ten exception). `internal/selection/selection_test.go::{TestDefaultRulesFiltersAggregationAndDeterminism, TestProjectAppliesExactOccurrenceDecisionsWithoutChangingAnalyzerEvidence, TestDefaultRulesExcludeSeparableParticlesButKeepAdverbs, TestAnalyzableStatisticsUsesSelectionFiltersBeforeLearnerExclusions, TestBookDeckEligibilityAcrossBooksBoundary}`; `internal/persistence/vocabulary_browse_counts_integration_test.go::TestVocabularyBrowseCountsMatchSelectionProjection`; `internal/persistence/current_reading_snapshot_integration_test.go::{TestCurrentReadingFreezesAndReleasesVocabularySnapshot, TestCurrentReadingFreezesCorpusQualifiedCandidates}` passed.

### 11. Sentence study already protects exact source alignment and some whitespace

**Source:** [`internal/webapp/sentence_study.go:64–102`, `alignSentenceStudy`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/webapp/sentence_study.go#L64-L102), plus `sentenceStudyAlignments` and `sentenceStudySegments` in that file; [`internal/webapp/concordance.templ`, `VocabularySentenceStudyPageView`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/webapp/concordance.templ); [`styles/vocabulary.css:338–360`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/webapp/styles/vocabulary.css#L338-L360).

**Executed preservation:** the stored sentence must exactly equal its `[start,end)` code-point slice of immutable unit text. Exact multiline text passes and remains in source segments; a space-normalized sentence against multiline unit text triggers whole-line fallback. Changing the NLP view without mapping offsets and sentence text back to authoritative source would violate this existing contract. **Risk:** actual verse wrapping, break layout between morphology units, fallback paragraph whitespace and narrow-screen accessibility need the later presentation prototype, not an agent declaration of visual acceptance.

**Affected contract / tests:** source-token evidence contract; `internal/webapp/sentence_study_test.go::{TestSentenceStudyLineAlignsOneToOne, TestSentenceStudyLineLocalFallbackKeepsNeighbours, TestSentenceStudyLineWholeLineFallback, TestSentenceStudyLineKeepsRepeatedFormsDistinct, TestSentenceStudyLineUsesCodePointOffsetsForGreek, TestSentenceStudyLineSurvivesMissingOrInvalidSyntax}`, captured sentence-study tests, and `internal/persistence/concordance_integration_test.go::TestGetVocabularySentenceStudyAttributesOnlyUniqueDecisions` passed. ### 12. Representative examples compose a generic text gate with German parsed GDEX

**Source:** [`internal/persistence/prepared_deck_inputs.go:248–321`, candidate sentence loading](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/persistence/prepared_deck_inputs.go#L248-L321); [`internal/persistence/cardexport.go:15–90`, batched parse read](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/persistence/cardexport.go#L15-L90); [`internal/cardexport/presentation.go:138–208`, `Freeze`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/presentation.go#L138-L208); [`cardexport.go:383–595`, text gates](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/cardexport.go#L383-L595), [`633–754`, ranking](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/cardexport.go#L633-L754), [`1228–1281`, apply/freeze decision](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/cardexport.go#L1228-L1281); [`internal/gdex/gdex.go:37–113`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/gdex/gdex.go#L37-L113).

Unresolvable references in a supplied map are skipped. A resolved sentence without tokens yields a **non-nil empty** token slice, so German syntax fails closed. Legacy/text-only callers and a nil corpus map use reference text without the GDEX overlay; the input loader only records a corpus map when rows exist. Thus normal modern persisted analysis supplies syntax, but not every helper/legacy/recovery input is equivalent. Actual missing-row fallback impact was not reproduced as a production failure.

**Executed / code-confirmed gates:** text must have 6–50 whitespace-delimited words and at most 400 code points, a whole-word target, valid source position, a complete language-specific boundary, no structural-noise rejection, and score at least 70. Ordinary German boundary requires a capital/number/opening quote start and literal final `. ! ?`; short interjections, continuations and some quote endings fail. **Any interior LF** is structural noise, regardless of whether it is an authentic verse break. An eight-word prose example scored 110 and passed; replacing one space with LF scored 100 but was rejected. The acceptance flag requires both score and absence of rejection reasons.

German non-nil tokens add a finite `VERB/AUX` **root** with subject-dependent knock-out; failure zeroes the score. Successful GDEX grades rank using subordinate-target/deixis/`PROPN` density/length factors, with an optimal 10–20-token window. Accepted first, then descending GDEX score, source offset, sentence ordinal, text: the generic points are not the gradual ranking. Best complete sentence is retained unchanged, not shortened to a line. The probe confirms nil parse differs from supplied empty parse, and accepts a supplied finite-root/subject skeleton without claiming it is an actual model parse.

**Affected contract / tests:** ADR 0062 intentionally retains the generic gate and German knock-out, amending ADR 0029's ranking only. `internal/cardexport/cardexport_test.go::{TestScoreSentenceQuality, TestBestSentenceEvidencePreservesCompleteSourceText, TestBestSentenceEvidenceRanksAllReferences, TestBestSentenceEvidenceRanksAcceptedReferencesByGradualGDEXScore, TestManifestRecordsPersistedGDEXDiagnostics}`; `sentence_evidence_test.go::TestBestSentenceEvidenceFromCorpusSkipsUnresolvedReferences`; `internal/gdex` tests passed. **Risk:** poetic omissions and parse sensitivity require real edition/analysis examples before any scoped relaxation is accepted. No claim that all sentence-based selection is wrong for poetry.

### 13. Contextual Gloss/translation gets one frozen sentence, not the Book's dramatic context

**Source:** [`internal/cardexport/presentation.go:213–241`, exact cache keys, and `350–367`, `workItem`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/presentation.go#L213-L241); [`workItem` source](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/cardexport/presentation.go#L350-L367); [`internal/enrichment/llm_codec.go:17–19`, prompts, and `169–247`, payload](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/enrichment/llm_codec.go#L169-L247); [`internal/enrichment/enrichment.go:536–564`, hashes](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/enrichment/enrichment.go#L536-L564); [`internal/enrichment/target_alignment.go`](https://github.com/justin-hayes/mouseion/blob/6e02d180b1015536127839e0a45953684c0e5a83/internal/enrichment/target_alignment.go).

**Code-confirmed / executed payload:** quality-approved frozen work supplies language, target language, canonical lemma, POS, tested surface, exact representative sentence and bounded lexical candidate senses. The contextual payload uses `i1`/short evidence handles. It excludes owner IDs, Book/resource titles, neighboring dialogue and separately typed speaker/stage-direction metadata. Literal speaker/direction words already in a selected sentence remain source content, not an attached role. Newlines are representable and survive JSON encoding in the isolated codec probe, but today's quality gate prevents an ordinary multiline candidate from reaching this point.

Cache keys bind provider/prompt, dictionary version, sentence and Meaning-evidence hashes. Sentence hashing normalizes CRLF to LF and trims edge whitespace only; interior LF versus space differs. Newline formatting is therefore not generally a cache-neutral change. Current contextual prompt asks for the complete sentence translation and one defensible brief English Gloss, supporting frozen evidence or honest context-only/unresolved outcomes; it contains no explicit verse-line preservation rule. Standard and Batch transports share the codec (`openai_batch_jsonl.go`); workers restore frozen work, not live Book context (`prepareddeck/standard_worker.go::restoreWork`).

English target alignment is optional ordered **exact** excerpts of the returned translation, unique, word-bounded and nonoverlapping. Invalid alignment is discarded as a whole without invalidating a defensible translation/Gloss. Rendering owns escaping and emphasis, never provider HTML; this is not a source-to-translation line alignment model.

### 14. Frozen specification is separate from Anki display; raw LF is not line-aware HTML

**Code-confirmed preservation:** the manifest freezes selected/omitted decisions, full representative sentence, tested form, parse evidence, source metadata, local lexical evidence and exact enrichment identities. **Executed renderer observation:** source bolding escapes text and inserts `<b>` spans but retains LF literally, not as `<br>` or typed line markup. Current Anki CSS does not set a preformatted whitespace rule for source/English sentences. The front is `{{Text}}`; the back reuses it, then displays headword/Gloss/full English sentence, not a duplicate source block. A multiline card is ordinarily omitted upstream; the renderer probe deliberately isolates the downstream capability.
