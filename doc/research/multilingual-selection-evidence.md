# Multilingual vocabulary-selection evidence (de/it/el)

Research for [issue #1245](https://github.com/justin-hayes/mouseion/issues/1245), checked 2026-09-27. This is evidence and a policy proposal, not a selection change or legal opinion. External-resource availability/licensing can change; verify exact artifact terms and version before bundling or redistributing anything.

## Existing contract (repository facts)

- [ADR 0048](../adr/0048-frequency-floor-deck-selection.md) selects every eligible unknown lemma occurring at least `N` times in the analyzed Book, default `N=3`; it expressly makes no coverage claim. The floor is post-analysis, preserving analysis denominators. [CONTEXT.md](../../CONTEXT.md) calls this **Recurring vocabulary** and says selection makes no coverage claim.
- Eligibility already has language-neutral identity `(language, canonical lemma, UPOS)`, owner/language-scoped Known and Reserved exclusions, proper-name/POS filters, sentence-quality constraints, and first-encounter card ordering ([ADR 0048](../adr/0048-frequency-floor-deck-selection.md), [ADR 0019](../adr/0019-generated-vocabulary-exclusion.md), [ADR 0050](../adr/0050-active-study-language.md)).
- The global DWDS frequency import was intentionally removed: book-local lemma counts suffice for the current floor ([ADR 0018](../adr/0018-remove-dwds-frequency.md); superseded rationale in [ADR 0008](../adr/0008-global-frequency-dataset-source-import.md)). Don't mistake the historical ADR 0008 license/source assertions for an active dependency.
- The normalized corpus now stores token, lemma, UPOS, sentence, and book/unit references per owner and analysis; study-language queries see current analyses ([ADR 0059](../adr/0059-persisted-normalized-corpus-for-concordance.md), [concordance foundation](../features/concordance-foundation.md)). This is direct evidence for per-Book, per-chapter, and across-library recurrence without importing third-party text. Cross-book rates remain conditional on that owner's chosen books and current analyses, not a population norm.
- Current Dictionary index is separate from frequency evidence: it provides senses/forms/IPA for `de`,`it`,`el`, not word-frequency counts. Its build derives a compact SQLite artifact from weekly Wiktextract/Kaikki English Wiktionary JSONL; ADR 0064 records CC BY-SA/GFDL attribution and size rationale, and ADR 0073 adds Greek ([ADR 0064](../adr/0064-dictionary-enrichment-provider.md), [ADR 0073](../adr/0073-modern-greek-language-support.md), [dictionary feature](../features/dictionary-gloss-enrichment.md)). Kaikki's first-party dump page confirms weekly updates, dump/extraction dates, and compressed per-language source file sizes of about 294 MB German, 41.6 MB Italian, and 108.2 MB Greek at the checked snapshot ([Kaikki raw downloads](https://kaikki.org/dictionary/rawdata.html)). That is the raw input, not the compact application index size.

No single validated, freely redistributable, lemma+UPOS frequency snapshot for all three current languages was established. In particular, “available to download” does not resolve reuse rights. Leipzig downloadable CC-BY corpora offer a viable *corpus* route when language/version is available, but add selection of comparable genre/date, local processing, artifact versioning and a lemma/POS mapping step. Existing Wiktextract dictionaries enrich selected items; they do not solve frequency/dispersion.

## What “beyond three occurrences” can mean

These are distinct signals; neither a third-party frequency rank nor global prevalence is equivalent to the learner's local recurrence:

1. **Within-Book support**: retain current count `c_book(lemma, UPOS)` and current `c_book >= 3` inclusion. This is the most direct, private, language-neutral eligibility condition and stays available with no external data.
2. **Within-Book dispersion**: count distinct EPUB units/chapters containing the lemma and optionally spread across normalized positions. Same total count concentrated in one chapter is different evidence from repeated use throughout. Use relative coverage / concentration, not raw chapter count alone (books differ in structure/segmentation). ADR 0066's declared-main-text scope helps avoid front/back matter inflating counts; chapter/unit identities already exist in source units/corpus rows.
3. **Owner-library recurrence**: count distinct current analyzed Books containing the same canonical lemma+UPOS in the same language, alongside owner-library occurrences and denominator of analyzed Books/tokens. Keep this clearly labeled as this learner's library evidence. Library size/genre selection biases it; it can be unavailable for a single-book library and must not imply population/commonness.
4. **External corpus evidence**: a corpus's normalized lemma frequency (e.g., per million) and document/context dispersion measure whether a lemma is common and broadly distributed in that reference corpus. Don't compare absolute counts across different corpora. POS/lemmatizer/genre/domain and corpus vintage must match or be recorded. A threshold can create systematic false exclusions of literary, technical, regional, inflected, newly coined and proper-name forms.

For candidate lexical false positives, keep POS and named-entity evidence as *independent features*: Mouseion already filters PROPN and uses NLP morphology/POS, but capitalization alone is weak (German nouns capitalize all common nouns; Greek casing/canonicalization differs). SUBTLEX-GR documents explicit mixed uppercase/lowercase behavior, but that is a corpus-specific diagnostic, not portable policy. Dictionary coverage may indicate there is an entry, not that the item is worth learning, common, or correctly lemmatized; missing dictionary entries are expected and existing fallback behavior is necessary.

## Policy recommendation (not a repository decision)

- **Do not silently replace or raise the floor using a global frequency cutoff.** Keep three as a deterministic no-external-data floor until an evaluated product decision establishes another value. A “larger deck” policy may select further candidates, but describe it as an explicit size/effort choice, not coverage or objective importance.
- **Use external frequency/dispersion to annotate/rank and prioritize review, not hard-exclude**, at least initially. Allow fallback to all eligible book-local `>=3` candidates when a source is missing, stale, unmatched, or legally unsuitable. Missing external evidence must not make one language lose cards or be treated as zero frequency. Record source/version and match status; don't synthesize de/it/el-equivalent confidence from incomparable datasets.
- **Evaluate book/library dispersion locally before adding resources.** It is free, privacy-preserving, reproducible from already stored data, and more aligned with reading the exact book/library. Prefer a surfaced evidence label/count over opaque scoring. For sparse books or no analyzable chapter mapping, fall back to book-local count with an explicit “no dispersion evidence” state.
- **Keep language-specific transformations, thresholds and confidence separate** while preserving shared identity/exclusion semantics. Greek Stanza GDT and normalization are different from German/Italian; the current Greek pipeline itself uses a different model and generic sentence-quality rubric (ADR 0073). A shared raw cutoff risks treating analyzer/corpus differences as learner differences.
- For a future decision, test against manually reviewed German, Italian and Greek book candidate sets. Measure false-exclusion (valuable terms suppressed), missed-word burden, false inclusion/noisy lemma rate, book and library dispersion calibration, dictionary/sentence-material availability, and learner review effort. Stratify short/long books, genres, POS, name-like candidates, per-language missing-source cases. Compare current N=3 with variants offline and use a no-external-data baseline/fallback; don't use benchmark accuracy from one genre as a universal threshold.

### Uncertainty / next verification

- Obtain/use the exact OSF SUBTLEX-IT license text and check whether the license covers database redistribution; no conclusion made here.
- Ask BCBL directly for the intended SUBTLEX-GR license and redistribution terms if it is shortlisted.
- Before a Leipzig import, inspect each exact artifact's metadata and its attached license; the official top-level terms distinguish text corpora (CC BY) from dictionary/statistics services/data (CC BY-NC).
- No runtime comparison, corpus download, or empirical candidate evaluation was conducted. Proposed dispersion metrics and fallback behavior above are product recommendations, not published findings.
