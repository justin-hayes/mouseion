# Design principles

Mouseion should be:

- text- and book-centered rather than dashboard-centered;
- information-rich but calm;
- serious but approachable;
- restrained rather than decorative;
- consistent across workflows;
- explicit about what numbers and recommendations mean.

Prioritize:

1. clarity;
2. accessibility;
3. consistency;
4. information hierarchy;
5. visual ornament.

Prefer reducing or demoting interface elements when the user's primary task
remains clear.

Book content and reading context should visually dominate application chrome
when both are present.
